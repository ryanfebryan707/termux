# Termux Scripts Collection

Kumpulan skrip Termux untuk Android yang dirancang untuk membantu tugas dan otomatisasi di perangkat mobile.

## 📋 Deskripsi

Repository ini berisi koleksi skrip Termux untuk perangkat Android, dengan tujuan untuk menyederhanakan tugas terminal dan mengotomatisasi workflow di lingkungan Termux.

## 🚀 Fitur

- Skrip otomasi untuk tugas-tugas umum
- Kompatibel dengan Termux di Android
- Mudah digunakan dan dapat disesuaikan

## 📦 Instalasi

1. Clone repository ini ke Termux Anda:
```bash
git clone https://github.com/ryanfebryan707/termux.git
cd termux
```

2. Berikan izin eksekusi untuk skrip:
```bash
chmod +x *.sh
```
